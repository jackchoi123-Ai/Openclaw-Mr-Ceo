# 小规模 Interior Design Firm（小公司 / 小工作室）的运作模式

> 适用对象：3–10 人的小型正规室内设计公司。
> 核心结论：小公司本质是 **"Principal 个人能力驱动"**，流程简单但高度依赖老板；大型公司则是 **"系统和团队驱动"**。
> 对照阅读：[大型 Interior Design Firm 的运作模式](interior-design-firm-operations.md)

---

## 1. 团队结构（高度重叠）

- **Principal / Owner**：几乎是全能角色（业务开发 + 设计总监 + 项目管理 + 部分施工监工）
- 1–3 名设计师（Senior + Junior）
- 1 名行政/助理（可选）
- 经常是 Principal 亲自带项目

## 2. 业务开发

- 主要靠 **口碑转介 + Instagram + 建筑师推荐**
- Principal 自己负责谈客户
- 很少有专职 Business Development 团队

## 3. 项目流程（大幅简化）

| 阶段 | 小公司做法 | 与大公司的主要区别 |
| --- | --- | --- |
| 接单 | Principal 直接谈 | 更灵活，但容易被客户要求过多修改 |
| 概念设计 | Principal 主导 | 速度快，但深度可能不足 |
| 深化设计 | 1–2 名设计师完成 | 经常 Principal 自己改图 |
| 施工图 | 简化版或外包 | 很多小公司会外包给绘图员 |
| 采购 | Principal 自己找供应商 | 议价能力较弱 |
| 现场监工 | Principal 或 Senior Designer 兼任 | 经常 Principal 亲自跑工地 |
| 项目管理系统 | Excel + WhatsApp + Google Drive | 很少用 Monday.com 这类专业系统 |

## 4. 项目类型

- 主要做高端住宅、私人别墅、SOHO、小型商业空间
- 很少接大型酒店、商场、医院等大项目（团队和资金实力不足）

## 5. 收入模式

- **设计费**：通常占项目总造价的 12–20%（比例比大公司高）
- **采购回扣**：很多小公司会依赖这部分收入
- **Principal 自己做设计**：利润更高，但工作量极大

## 6. 优缺点对比（小公司 vs 大公司）

| 项目 | 小公司 | 大公司 |
| --- | --- | --- |
| 灵活性 | 高 | 低 |
| 专业分工 | 低 | 高 |
| 质量控制 | 依赖 Principal 个人能力 | 有系统审核 |
| 同时接项目数量 | 通常 3–6 个 | 8–20 个 |
| Principal 工作强度 | 非常高 | 相对较低 |
| 客户类型 | 中高端住宅为主 | 商业 + 高端住宅 |

## 7. 现实情况

很多小公司最终会面临以下问题：

- Principal 太累（既要谈客户、做设计、监工，又要管钱）
- 难以规模化
- 容易因为一个大项目出问题而倒闭
