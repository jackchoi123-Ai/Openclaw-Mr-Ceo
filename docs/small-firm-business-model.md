# 小型室内设计公司的商业模式（3–10 人）

> 目标：从"被动接单、靠老板硬撑"，变成**定位清楚、产品化、先收钱后做事、能复制**的小公司。
> 文中的价格、比例和毛利是示范数字，请换成你自己的实际数据。
> 配套阅读：[小公司运作模式](small-interior-design-firm-operations.md) · [实用模板](templates/)

---

## 一页看懂：商业模式画布

| 要素 | 小型室内设计公司的做法 |
| --- | --- |
| **目标客户** | 选一个细分：例如某区域的新房 condo / landed 业主、翻新屋主、小型商铺 |
| **价值主张** | "一站式、透明报价、准时交付、有善后"，而不是"最便宜" |
| **产品** | 付费咨询 → 设计套餐 → 设计 + 施工 → 软装 → 保养维修 |
| **获客渠道** | 口碑转介、Instagram / Facebook / 小红书、房产中介、开发商交屋活动、在建工地开放参观 |
| **客户关系** | 固定流程、书面确认、项目群组每周进度更新、完工后回访 |
| **收入来源** | 设计费、施工利润、材料差价、软装利润、变更单、保养合约 |
| **关键资源** | Principal 的设计能力和口碑、作品集、可靠的外判名单、供应商渠道 |
| **关键活动** | 销售与报价、设计、采购、现场管理、收款 |
| **合作伙伴** | Labour-only 外判、材料供应商、定制柜工厂、房产中介、建筑师 |
| **成本结构** | 人工（最大）、租金、外判工钱、材料、营销、软件 |

## 1. 定位：先选一个细分市场

小公司最大的问题是什么都接，结果每个项目都从零开始，报价慢、出错多、客户也难决定。

**选细分的三个标准**
1. 你过去做得最多、利润最好的项目类型。
2. 客户预算足够（例如工程 RM 80,000–300,000）。
3. 项目相似度高，可以重复使用设计、材料和外判。

**示例定位**
- "专做巴生谷新交屋 condo 的全屋设计和施工，8–12 周交付。"
- "专做 20–30 年老 landed 房子翻新。"
- "专做咖啡店、诊所等 1,000–3,000 平方尺的小型商业空间。"

定位越清楚，转介越容易（"他专做这种"），报价越快，客户越容易下决定。

## 2. 产品阶梯：把服务做成"产品"

| 层级 | 产品 | 示范价格 | 作用 |
| --- | --- | --- | --- |
| 0 | **付费咨询 / 量房** | RM 300–1,000，签约后抵扣 | 筛掉只来拿免费方案的人 |
| 1 | **设计套餐**（Design Only） | 按平方尺或固定价，分 2–3 档 | 给只要设计的客户，也是进入施工的门票 |
| 2 | **设计 + 施工**（D&B，主力） | 工程总价 | 主要收入和利润来源 |
| 3 | **标准套餐**（例：condo 全屋套餐） | 按房型 / 平方尺定价，Good / Better / Best 三档 | 报价快、客户决定快、施工可复制 |
| 4 | **软装与家具** | 按清单报价 | 提高客单价，利润好 |
| 5 | **保养维修 / 小改造** | 按次或年费 | 维持客户关系，带来转介 |

**标准套餐是解决"客户难决定"的关键**：
- 三档价格，材料和做法都已定好，客户只需要选一档，再加减少量项目。
- 你的采购、外判和工期都能标准化，毛利更稳定。

---

## 3. 收入与毛利结构（示范）

| 收入来源 | 示范毛利率 | 说明 |
| --- | --- | --- |
| 设计费 | 高（主要是人工成本） | 设计 + 施工项目可部分抵扣 |
| 施工（Labour-only 外判 + 自己采购材料） | 目标 20–30% | 主要利润来源 |
| 材料差价 | 视品类 | 透明报价，不要靠隐藏回扣 |
| 软装家具 | 目标 20–35% | 完工前推，客户最需要的时候 |
| 变更单（VO） | 与施工相同 | 先报价、先收款再做 |
| 保养维修 | 中等 | 金额小，但带来回头客和转介 |

> 建议：报价透明（分项列出），利润放在服务和管理里，不要靠隐藏回扣。透明报价反而让客户更快信任、更快决定。

---

## 4. 销售流程：每一步都有决定点

| 步骤 | 做什么 | 决定点 / 收款 |
| --- | --- | --- |
| 1 初次咨询 | 问清预算、入住时间、谁拍板 | 不符合定位或预算的客户礼貌转介出去 |
| 2 付费量房 + 概念 | 量房、了解需求、给 2 个方向 | 收咨询费 |
| 3 报价 | 套餐或分项报价，**14 天有效** | 档期要交订金才锁定 |
| 4 签约 | 合同 + 付款节点表 | 收订金 20–30% |
| 5 设计确认 | 每次会议发确认单 | 定制品下单前收材料款 |
| 6 施工 | 每周进度更新 | 每个阶段开始前收进度款 |
| 7 交接 | 一起做缺陷清单 | 交钥匙前收尾款 |
| 8 售后 | 1 个月、3 个月回访 | 请客户写评价、介绍朋友 |

用到的模板：[客户付款节点表](templates/client-payment-schedule.md)、[会议确认单与变更单](templates/client-confirmation-message.md)。

## 5. 交付模式：轻资产、可控

| 环节 | 做法 |
| --- | --- |
| 设计 | Principal 定方向，设计师出图；建立标准图库和材料库 |
| 采购 | **材料自己买**，和 2–3 家主要供应商谈月结和批量价 |
| 施工 | **Labour-only 外判**，按完成量付款，扣 10% 保留金 |
| 现场管理 | 1 名 PM / 监工负责多个工地，每日照片、每周进度报告 |
| 善后 | 自己养 1 名杂工处理小问题，大问题按外判合同回来处理 |

用到的模板：[外判合同关键条款](templates/subcontract-key-clauses.md)。

**不建议太早做的**：自己养施工队、买大量库存、开大展厅。都会占用现金，增加固定成本。

## 6. 算账：每个月要做多少项目才打平

**示范数字**

| 项目 | 金额 |
| --- | --- |
| 每月固定成本（人工 + 租金 + 软件 + 营销） | RM 40,000 |
| 平均每个项目合同额 | RM 120,000 |
| 平均毛利率 | 25% |
| 每个项目毛利 | RM 30,000 |

**打平所需项目数** = 每月固定成本 ÷ 每个项目毛利 = 40,000 ÷ 30,000 ≈ **每月 1.3 个项目**，一年约 **16 个项目**。

由此可以倒推：
- 一年要签 16 个项目，如果签约率是 30%，就需要约 **53 个付费量房**，每月约 4–5 个。
- 如果每个项目工期 3 个月，同时进行的项目约 **4 个**，符合小公司 3–6 个的产能。

把示范数字换成你自己的，就知道要提高哪一个：客单价、毛利率，还是签约率。

---

## 7. 每月要看的 8 个数字

| 指标 | 说明 |
| --- | --- |
| 询问数（Leads） | 每月新询问 |
| 付费量房数 | 愿意付咨询费的人 |
| 签约率 | 签约数 ÷ 付费量房数 |
| 平均合同额 | 每个项目的平均金额 |
| 项目毛利率 | 每个项目完工后结算 |
| 收款天数 | 发票到收款平均几天 |
| 变更单金额 | 每个项目的 VO 收入 |
| 转介率 | 新客户中来自转介的比例 |

---

## 8. 12 个月落地路线

| 时间 | 重点 |
| --- | --- |
| 第 1–3 个月 | 定细分市场；改合同和付款节点；开始收咨询费；每次会议发确认单 |
| 第 4–6 个月 | 推出 1 个标准套餐（三档）；外判改成 Labour-only；建立外判评分 |
| 第 7–9 个月 | 请 1 名 PM / 监工，Principal 退出日常跑工地；建立标准图库和材料库 |
| 第 10–12 个月 | 加入软装和保养服务；建立转介奖励；每月检查 8 个数字 |

## 总结

小型室内设计公司的商业模式，关键是四件事：

1. **定位**：选一个细分，做到"一提这种项目就想到你"。
2. **产品化**：付费咨询、标准套餐、分档报价，让客户容易决定。
3. **现金流**：先收钱再做事，客户付款比外判付款早一步。
4. **轻资产交付**：材料自己买、外判只包工、PM 管现场，让老板从"什么都做"变成"管方向、管销售、管品质"。
