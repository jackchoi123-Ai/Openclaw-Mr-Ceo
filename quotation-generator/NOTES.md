# 报价生成器 Quotation Generator — 项目记录

最后更新：2026-10-27　状态：**第一版完成，待试用**

## 这是什么
单文件网页工具（`index.html`，无依赖、无需联网）。员工填资料 → 右侧实时预览 A4 报价单 → 「导出 PDF」。
格式和计算逻辑照公司的报价单 **Q10357（Mr Brandon，Amverton Park 扩建 + 装修）**。

## 怎么用
1. 下载 / 打开 `quotation-generator/index.html`（Chrome 或 Edge）。
2. 「载入范例 Q10357」看完整范例；「新建」开始新报价。
3. 「导出 PDF」→ 打印窗口里目标选"另存为 PDF"。

## 已完成的功能
- 报价资料（单号、版本、参考号、日期、付款条件、有效期、客户、工程名称）
- 工程项目：行类型 = 项目（数量×单价）/ 小标题 / 备注 / 小计；可上移、下移、复制、删除
- 价目表：输入描述后 Tab 自动带出单位和单价（预设来自 Q10357，可增删改）
- 费用：监工费（默认 2.5%）、折扣、SST（可选）
- 条款可编辑，`{{validUntil}}` 自动带入有效期；公司资料可改
- 保存：浏览器 localStorage；「导出文件 / 导入文件」用 JSON 在同事之间传递
- 范例 Q10357 已核对：12 个项目的小计与原报价单一致，总计 **RM811,751.83**

## 关键决定 / 业务规则
- **监工费 = 小计 × 2.5%**（791,953 × 2.5% = 19,798.825 → 19,798.83）。
  原报价单上有一张阶梯表（5% / 4% / 3%），但与实际结果对不上，**没有照它算**。如有阶梯规则需要补。
- 金额四舍五入到分，逐行取整后再加总（和原报价单一致）。
- 条款文字照原报价单；被截断的 "Intellectual Property" 那条我补全了。
- SST 默认不加，条款写 "excluded"。

## 已知限制
- 保存只在各自电脑的浏览器里，**员工之间不同步**；换电脑 / 给别人要用「导出文件」。
- 没有登录和权限。
- 只在 Chromium 内核浏览器测过导出 PDF，Safari 的分页没测。
- 单价输入框不带千分位（预览里才显示 1,000.00）。
